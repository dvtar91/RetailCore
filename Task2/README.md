Задание 2. Анализ текущего состояния

Что нужно сделать: зафиксировать текущее состояние платформы и представить архитектурный контекст системы.
Конкретные задачи
Подготовьте:
Architecture Canvas, в котором отразите цели бизнеса, стейкхолдеров, требования, ограничения, риски, проблемные зоны и ключевые особенности текущей архитектуры. При разработке ориентируйтесь на шаблоны Software Architecture Canvas.
AS-IS диаграмму контекста, где покажите основные части системы, внешних участников, ключевые интеграции, основные потоки данных, а также проблемные зоны и зависимости.
Краткий анализ артефактов, на основании которых вы восстанавливали текущее состояние системы.
Для анализа используйте: 
Три стенограммы интервью с разработчиками, чтобы разобраться в фактическом поведении системы, локальных обходных решениях, технических ограничениях и скрытых зависимостях.
